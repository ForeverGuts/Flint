# ROADMAP_RULES — 开发路线图书写规则

> 本文件是 `Log/ROADMAP.md` 的**格式规则书**。
> AI 在项目阶段变更或规划新模块时，**必须**按此规则更新 `Log/ROADMAP.md`。

---

## 格式

### ✅ 已完成

按时间倒序列出已完成的模块，每项一行：

```
- **模块名** — 简要说明
```

### 🔜 待开发（按优先级降序）

分四个优先级：

| 层级 | 含义 | 示例 |
|------|------|------|
| **P0** | 核心基础设施 | 持久化存储、上下文管理 |
| **P1** | Agent 可用基础 | 命令系统、模型切换 |
| **P2** | 能力扩展 | 工具系统、技能系统 |
| **P3** | 高级交互 | 事件订阅、多会话、RPC |
| **P4** | 生产化 | 配置增强、错误日志 |

每项格式：

```
- [ ] **模块名** — 一句话描述
  - 依赖：前置模块（可选）
```

### 📊 依赖关系图

使用文本图表展示模块间的依赖顺序。

### 🧭 实施建议

按顺序列出优先实施的模块和理由（1-3 条即可）。

## 示例

```
## ✅ 已完成

- **项目骨架搭建** — ESM + TypeScript 严格模式

## 🔜 待开发

### P0 — 核心基础设施

- [ ] **持久化存储** — 实现 JSONL 文件存储后端
  - 依赖：SessionStorage 接口已就绪
```
