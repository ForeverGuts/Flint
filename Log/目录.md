## 文件调用关系

```
index.ts
  └─ initTerminal()
  └─ Harness.run()
       └─ check()
            ├─ 读取 config/api.json
            └─ createProvider() → DeepSeekProvider
       └─ main(checkResult)
            └─ createRuntime({}) → Runtime(llm)
                 └─ runReplMode(runtime)
                      └─ getUserInput() → readLine()
                      └─ runtime.prompt(input, onToken)
                           └─ llm.stream() → yield chunk
                                └─ onToken(chunk) → process.stdout.write()
```
