# 📁 项目目录结构

```
Ts_Agent/
│
├── .gitignore          # Git 忽略规则
├── package.json        # 项目配置 + 依赖 + 脚本（ESM, type: module）
├── tsconfig.json       # TypeScript 编译器配置（严格模式）
├── CLAUDE.md           # AI 助手行为规范
│
├── src/
│   ├── index.ts        # CLI / Library 双模式入口，解析参数、连接 main.ts
│   ├── main.ts         # Agent 核心逻辑骨架（生命周期、任务调度、工具管理）
│   └── types.ts        # 项目全局类型、接口、枚举定义
│
└── Log/
    ├── CHANGELOG.md    # 变更日志（时间倒序）
    └── 目录.md          # 本文件，目录结构与职责说明
```

## 🔄 工作流

### 开发 → 运行

```
src/*.ts  ── npm run dev ──▶ tsx 直接运行（开发热更新）
src/*.ts  ── npm run build ▶ tsc 编译到 dist/
dist/*.js ── npm start     ▶ node 运行（生产）
```

### 文件调用关系

```
src/index.ts             ← 入口，CLI / Library 双模式
  └── src/main.ts        ← Agent 核心骨架（生命周期、任务调度）
        └── src/types.ts ← 全局类型定义（被 main.ts / index.ts 引用）
```
> 注：新增文件后同步更新 `Log/目录.md` 和 `Log/CHANGELOG.md`。

### 职责边界

| 目录/文件 | 职责 | 是否提交 |
|-----------|------|---------|
| `src/index.ts` | 入口：CLI 参数解析 + Agent 启动 | ✅ 是 |
| `src/main.ts` | Agent 核心逻辑骨架 | ✅ 是 |
| `src/types.ts` | 全局类型 / 接口 / 枚举 | ✅ 是 |
| `dist/` | 编译产物 | ❌ (.gitignore) |
| `node_modules/` | 依赖包 | ❌ (.gitignore) |
| `Log/` | 文档和变更记录 | ✅ 是 |
| 根目录配置文件 | 项目环境定义 | ✅ 是 |
