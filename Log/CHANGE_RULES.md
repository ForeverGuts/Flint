# CHANGE_RULES — 变更日志书写规则

> 本文件是变更日志的**格式规则书**，不包含实际记录。
> AI 在每次功能开发、Bug 修复、重构或配置改动后，**必须**按此规则将记录写入 `Log/CHANGE_LOG.md`。

---

## 格式

```
YYYY-MM-DD HH:mm | [类型图标] 描述
```

- 每段描述最多 1 行
- 不同日期的记录之间用空行隔开
- 时间通过 `date` 命令获取系统当前时间，禁止估计

## 类型释义

| 图标 | 类型 | 适用场景 |
|------|------|---------|
| 🚀 | Init | 项目初始化 / 骨架搭建 |
| ✨ | Feature | 新功能开发 |
| 🐛 | Fix | Bug 修复 |
| ♻️ | Refactor | 重构 / 目录清理 / 代码重组 |
| ⚡ | Optimize | 性能优化 |
| ⚙️ | Config | 配置文件变更 |
| 📝 | Docs | 文档 / 注释 / 知识库 |
| 📦 | Env | 环境 / 依赖安装与升级 |
| ✅ | CI | 编译 / 构建 / 验证 |

## 示例

```
2026-07-23 18:00 | [Docs📝] 拆分规则与数据职责，CHANGE_LOG 独立
2026-07-23 17:35 | [Feature✨] 新增流式输出 SSE 解析
2026-07-23 17:00 | [Config⚙️] 新增 config/api.json 配置文件

2026-07-19 15:08 | [Init🚀] 初始化 TypeScript + ESM 项目环境
```

## 输出路径

```
Log/CHANGE_LOG.md
```
